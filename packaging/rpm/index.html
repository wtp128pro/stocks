Stocks: signed RPM repository

Packages and repository metadata are signed with the key below. Source and documentation: github.com/wtp128pro/stocks.

Install (Fedora, dnf5)

sudo curl -fsSLo /etc/yum.repos.d/stocks.repo https://wtp128pro.github.io/stocks/stocks.repo
sudo dnf install stocks

dnf asks you to confirm the key fingerprint on first use. Compare it with the one below.

Signing key

RSA 4096, created 2026-10-10, expires 2029-10-09
Fingerprint: 1910 F9DB 58D0 7BF5 83CC  BB6F 9226 BBD4 F352 B9A6

RPM-GPG-KEY-stocks (ASCII-armored public key). The fingerprint is also in the README and on each GitHub release.

Verify a downloaded RPM by hand

sudo rpm --import https://wtp128pro.github.io/stocks/RPM-GPG-KEY-stocks
rpm -K stocks-*.rpm        # must print: digests signatures OK

A package without a signature also exits 0 and prints only digests OK; look for signatures OK.
